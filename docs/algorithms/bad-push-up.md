# 旧不标准俯卧撑记录的兼容说明

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `BAD_PUSHUP`。独立训练入口已移除；它与[俯卧撑](push-up.md)共用 `PushUpCounter`。旧记录主成绩仍显示不标准次数，并标注旧记录；普通俯卧撑的主成绩仍为有效次数，同时显示不标准次数，不是另一个识别模型。

历史筛选与同类播放列表将 `bad_pushup` 归入俯卧撑，但仍按旧类型加载、回放和保留原始成绩。动作卡片最佳只比较旧记录中实际保存的 `goodReps`，不把 `badReps` 算作有效成绩；旧模式的个人校准不自动应用于普通模式。成长星球种类进度按合并后的种类重算，可能减少，记录条数和日期不变。

## 输入和判定

输入为滤波后的肩、肘、腕、髋、膝、踝点。先要求躯干与水平夹角 `<55°`、手腕相对肩高度比例 `>0.02`；再以肘角深度与肩腕相对下降深度的较大值作为运动信号。下放深度 `>0.22` 后进入阶段，回到 `≤0.10` 时结算；阶段不足 `350 ms` 忽略。

未校准时，本次最低肘角 `≤100°` **或**最大下降深度 `≥0.85` 算默认幅度到位。可能记为不标准的因素：

- **幅度不足**：没有满足到位条件；若既没有明显下放（肘角 `≤122°` 或下降深度 `≥0.45`）又没有判出姿势错误，极小往返会忽略，不一定计为不标准。
- **身体不直**：髋到肩—踝线距离超过 `0.13` 倍躯干；或被视为侧面时肩—髋—踝角 `<150°`。
- **跪姿代理**：髋—膝—踝角 `<120°`。这是二维膝角规则，并没有检测膝盖与地面接触。

同一往返若姿势和幅度都不符合，代码优先给姿势原因；一次不标准往返增加 `badReps` 和姿势提醒。标准往返仍可增加 `goodReps`，但该模式大号成绩显示 `badReps`，详情可显示两者。

## 个人校准

旧训练中按“个人校准 +1”成功时，本模式**立即记入一次不标准次数**；以后以保存的个人目标和姿势容忍判定，必须先回到撑起位。达到个人目标但没有达到默认幅度或姿态的往返，在该模式仍可能记入不标准并提示“按个人目标计入不标准动作”。如果一侧点不可靠、采样不稳定或几乎没有移动，校准可能拒绝。个人目标不代表动作标准或安全。

## 场景与优缺点

这些规则仍用于旧记录回放；现在请使用普通俯卧撑入口观察浅幅和姿势提示。

- **优点**：沿用完整往返状态机，能解释触发原因，并与有效次数区分；具备最短时长、失踪保护和手动目标。
- **缺点**：不标准是少量二维规则的分类，不是对动作质量的全面评审。关键点缺失时部分姿势判据会退化；髋部视角、衣物、遮挡或单路深度异常都可能造成错误提示；系统不能判断疼痛、负荷或关节真实受力。

## 与同类方案比较

单角度规则更简单，但难描述全身姿态；姿态时序分类器可尝试学习更多错误类型，需要专家一致标注、样本覆盖、隐私及域外泛化评估，不天然更可靠。多摄像头或 IMU 可补充可见性/运动信息，增加标定或佩戴成本，仍不能单独证明动作安全。详见[索引中的方法比较](README.md)。
