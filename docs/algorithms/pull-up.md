# 引体向上算法

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `PULLUP`，主成绩为有效次数；支持个人目标。当前没有横杆检测，也没有下巴关键点或接触传感器。

## 输入和实际判定

使用肩、肘、腕、髋等二维点。肘角为肩—肘—腕夹角；`wristDropRatio = (腕代表点 y − 肩代表点 y) / 躯干长度`。

1. **悬挂姿态代理**：`−wristDropRatio ≥0.15`，即手腕相对肩至少高 `0.15` 倍躯干。该条件不证明手握杆或身体悬空。
2. **悬垂基准**：默认肘角 `≥150°` 时记录肩腕垂直距离的基准 `hangReach`。上升量为 `hangReach − (−wristDropRatio)`，两个量都已相对躯干归一化，不再除一次尺度。
3. **阶段**：当前肘角 `<145°` 进入拉起，恢复到 `≥150°` 时结算；阶段 `<400 ms` 忽略。肘角额外平滑值主要用于界面进度，阶段使用滤波骨架计算的当前肘角。关键点长期不可用超过 `600 ms` 时丢弃未完成阶段。
4. **默认到位**：本次最小肘角 `≤95°`，且身体相对悬垂基准的最大上升量 `≥0.10` 倍躯干，记为有效。只弯手臂而身体上升不足不计数；上升足够但未到位时，肘角 `≤118°` 等“明显移动”条件可记为不标准。

界面可能提示“下巴没过杆”，但这只是依据角度/位移的推测：**当前不能测量下巴相对横杆的位置**，也不能可靠区分借力摆动。建议镜头尽量拍到手、肩肘和全身，人物与杆的实际位置仍需人工核对。

## 个人目标、优缺点

个人校准以连续三帧建立悬垂起始参考，在当前最高位置确认；检查手臂点和采样稳定性，要求至少有一定上升。确认成功即记一次，保存个人肘角目标和最小上升量，并等待回到悬垂位。此目标不是下巴过杆或动作安全认证。

- **适合**：固定机位、单人、手臂无遮挡且能看见完整身体的辅助计数。
- **优点**：肘角加身体相对上升，避免将部分单纯弯肘直接计为有效；可用有限运动幅度设置个人目标。
- **缺点**：相对尺度会随躯干姿态/点误差变化，遮挡、身体摆动和机位变化可误判；没有杆、手握、下巴和真实离地识别，单人模型也不提供稳定身份保证。

## 与同类方案比较

只用肘角的计数更轻，但更难排除只弯手臂；本方法加入相对上升量，仍无法判断是否过杆。可以研究**杆检测 + 下巴位置 + 多视角**来估计过杆，或增加器械接触传感器；它们需要数据、可见性、几何标定或硬件，不保证安全。时序分类可研究摆动/借力，但必须有明确标注及泛化评测。通用比较见[索引](README.md)。
