# 自由倒立算法

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `HANDSTAND`，主成绩为最长单组有效时间；不支持个人校准。相同判定器的[靠墙变体](wall-handstand.md)使用不同容忍阈值。

## 判定流程

输入为肩、髋、脚踝的二维关键点，至少一侧肩髋和一侧脚踝须可靠。图像 y 向下：

1. **倒置**：肩代表点的 y 比髋大 `0.02` 个画面宽单位以上；至少一只脚踝可靠，所有可靠脚踝的 y 都小于肩 y。另一只脚不可见时不能证明其也被抬起。
2. **接近竖直**：躯干与竖直方向夹角 `≤25°`。
3. **稳定代理**：最近最多 `12` 帧的髋 x 峰峰值 / 该窗口平均躯干尺度 `≤0.18`；不足 3 帧时暂不以漂移否定。窗口是帧数而非固定秒数，采样率变化会改变覆盖的时间。
4. 满足上述条件持续 `300 ms` 进入保持，候选段计入；相邻合格帧累计有效时间。姿势破坏或人体不可用时通常按 `700 ms` 宽限处理，超限结束一组。**当前起算帧未设置 `lastGoodMs`，紧接的失效帧可能直接结束本组**，不应承诺起算后一定有完整宽限。
5. 主成绩为最长单组，训练详情显示本组、累计、组数和稳定度；汇总保存最长、累计和稳定度，组数不是独立的持久化字段。稳定度由最近髋漂移得分（权重 `0.6`）与保持帧平均躯干倾角得分（权重 `0.4`）组成，仅是启发式数值。

## 适用场景与优缺点

- **适合**：手机固定、足够距离拍全身，脚踝、肩和髋可见；周围空间和防护由使用者自行确认。
- **优点**：倒置、倾角和短期漂移共同限制，不仅凭单帧肩髋上下位置；只累计已观察到的有效时间，短遮挡有一定容忍。
- **缺点**：二维投影无法证明双手支撑、真正离地或未靠墙；单侧脚踝可见时另一侧不受检验。12 帧窗口、身体尺度、关键点和左右侧切换均可能影响稳定度；翻转/遮挡、人太小、手机倾斜、时延也可能误判。即使计时成功也不是安全、标准或技能认证。

## 与同类方案比较

只用倒置角度的静态规则更容易实现，但弯腰或瞬时姿态可能误触发；本方案增加脚踝和漂移。多视角估计或 IMU 能提供额外空间/运动信息，但需标定或佩戴且仍无法独立证明手部承重；压力传感器可补充接触证据。姿态分类模型需要倒立、翻身和遮挡的标注数据。各方案及来源见[索引](README.md)，没有本项目对照实测。
