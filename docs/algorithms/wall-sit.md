# 靠墙蹲算法

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `WALL_SIT`。主成绩是**多组有效时间累计**，另存本组和最长单组；不支持个人校准。

## 输入与姿态判定

使用肩、髋、膝、踝二维点；膝角由可信同侧或双侧融合得到，膝高度使用可信侧或加权中点。当前同时要求：

| 指标 | 默认条件 |
| --- | --- |
| 膝角（髋—膝—踝） | `60° ≤ 膝角 ≤ 110°` |
| 坐姿 | 髋在肩下方，至少相差 `0.02` 个画面宽单位 |
| 髋膝高度差 | `abs(髋 y − 可信膝 y) / 躯干长度 ≤0.30` |
| 躯干 | 与竖直方向夹角 `≤30°` |

这些条件只是二维坐姿代理；**躯干竖直不等于背部贴墙**，算法不检测墙面或接触。可在一侧膝点缺失时利用可信侧，但不能证明另一侧动作正常。

## 计时和成绩口径

1. 持续合格 `400 ms` 后起算，候选段计入有效时间；起算帧设置为最近合格帧。
2. 后续合格帧由 `HoldClock` 累计相邻合格帧的间隔。姿势不合格时暂停累计，`800 ms` 内恢复可继续本组；人体或必要点缺失调用中断处理，距上次合格超过 `600 ms` 可结束本组。超过 `500 ms` 的相机帧间隔先插入失效通知，不能把整段空白当作已观察到的合格时间。
3. 大号成绩是已结束组的有效时间加当前组有效时间；详情区分本组、组数、累计和最长单组。保存时 `holdMs` 仍是最长单组，`totalHoldMs` 是累计，组数不是独立的持久化字段；旧记录未存累计时不能把最长当作累计。带骨架的历史回放可以按当前算法重算，结果不一定等于旧版当时保存值。
4. 稳定度为 `clamp(1 − 膝角标准差 / 20°, 0, 1)`；统计代码中保持后的合格帧、跨本次训练累计，并非受力或肌肉疲劳评价。

例如两组分别有 3.234 秒和 1.254 秒有效时间，累计为 4.488 秒，最长仍为 3.234 秒；这是合成回归示例，不是手机计时精度。

## 适用场景、优缺点

- **适合**：固定侧面或斜侧机位，肩、髋、膝和脚踝尽量清楚，单人进行静态保持。
- **优点**：姿态、起算、有效时间与宽限分开，可解释；一侧腿点短暂遮挡时有可信侧兜底；多组累计与最长分开。
- **缺点**：角度/高度均为二维估计，透视、遮挡、相机横滚和低帧率影响结果；无法确定真正贴墙或承重，标准差不等于稳定或动作安全。长丢帧、初始候选和回放需真实设备验证。

## 与同类方案比较

单膝角计时更简单，但不足以区分部分站立/半蹲；本方法增加髋膝高度和躯干角。墙面分割/多视角可提供墙的几何位置，仍不能仅凭图像保证真实接触；墙面压力/接触传感器可提供更直接证据，但需要额外硬件。当前方案适合低成本辅助计时，不适合把“贴墙”作为可信测量。更多方法见[索引](README.md)。
