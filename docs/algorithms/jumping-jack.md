# 开合跳算法

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `JUMPING_JACK`，存储键 `jumping_jack`，算法版本 `fitness-2026-11-jack1`。识别双臂和双脚同时张开，再回到合拢位；主成绩是有效次数，另保留待调整次数。阈值属于启发式，尚无真人视频或设备准确率数据。

## 使用方法

固定手机，单人尽量正对或背对镜头，给上举的手和张开的脚留出画面空间。先站直、放下双臂、合拢双脚并停留片刻，再同时打开双臂和双脚，随后回到合拢位。建议按舒适节奏练习；场景提示中的关键点置信度不是定位准确率。若用户当前幅度尚不能达到默认标准，可使用个人校准。

**二维关键点无法证明双脚真的离地或落地**：双手上举同时双脚向外迈步，也可能满足计数规则。算法不能检测接触、发力、疼痛、心肺负荷或安全性；不代表对标准动作或健康状况的认证。

## 输入与几何

动作使用训练流水线中越界屏蔽、重力对齐、滤波后的帧。双肩、双髋、双腕、双踝必须同时可信（入画值 ≥0.5，坐标有限），任一缺失时不凭单侧补出动作。场景诊断同样提示这些双侧点是否可见；肘和膝用于骨架显示，不是本动作的必要判据。

- `L`：左右肩中点与左右髋中点的二维距离，须 ≥0.04 画面宽。水平肩宽 / `L` 须 ≥0.25，肩中点到髋中点、髋中点到双踝中点的向下投影各须 ≥0.5 倍 `L`；这是粗略站直和正/背面条件，不是准确的机位识别。
- 两侧分别计算 **髋—肩—腕二维夹角**，以较小值 `A` 代表双臂中抬得较少的一侧，以较大值判断是否两臂都已放下。两手真实高度、肘部伸直和身体三维角度并不可由此确认。
- 两个脚踝在水平方向相对于髋中点的位置各除以当帧的 `L`，按画面从左到右排序。建立的合拢位分别为 `B左、B右`；当前左踝向外量 `左外 = B左 − 当前左`，右踝向外量 `右外 = 当前右 − B右`，总增量 `D = 左外 + 右外`。同时保存合拢时左右脚踝各自的画面 `x`，计算两脚相对于固定画面向外的位移，各除以当前帧 `L`；这样髋部平移不容易让画面中静止的脚误称向外。水平翻转或固定平移不改变这些关系，但手机/人体移动、透视、画面裁剪、躯干长短抖动或转身仍会影响结果。

## 阶段与默认计数

1. **合拢基准**：较大的肩部夹角 ≤45°，双踝间距 / `L` 不超过 `min(1.6, max(1.05, 1.4×肩宽/L))`；连续三帧左右踝相对偏移各自极差 ≤0.12 才建立基准，采用窗口内较宽的一对，降低偶发抖动放大位移的风险。
2. **打开**：基准建立后，默认任一臂夹角 >55° 或任一侧脚踝向外量 >0.08 即开始记录一个阶段。需要**同一帧**同时满足手臂和双脚证据，不能把先挥臂、再单独迈腿的不同时刻峰值拼成一次。
3. **默认有效**：同一帧 `A ≥135°` 且双腕均高于对应肩，`D ≥0.35`，双踝分别相对髋部及合拢时画面位置都向外 ≥0.098 倍躯干，且张开后双踝间距 ≥1.15 倍肩宽。当单臂、单独挥臂、双脚独自打开或单脚迈步没有形成足够的双侧同步证据时不计数；相对画面的双脚检查减少了单脚静止且髋部偏移的误计，但相机晃动、关键点误检等仍可能造成误判。
4. **回合拢**：两臂放下，双踝间距回到基准增量 ≤0.175，并满足上述合拢上限后才结算。进入打开阶段到返回不足 250 ms 的动作不计；初始就在张开位或离开时尚未合拢也不会补计。
5. **待调整**：进度条参考双臂、总脚距及较弱一侧的相对移动，不代表姿势安全；若未到默认有效标准，但同一帧双臂角度 ≥70°、间距增量 ≥0.15 且两脚相对髋部和画面各自向外至少约 0.042 倍躯干，回合拢后记一次待调整；活动太小或只有一组信号不计。完成后的原因提示在合拢帧最多保留约 1.2 秒；采用个人目标时，待调整阈值随目标降低，见代码。两臂/脚是否正确伸展、是否安全均不能仅凭此分类判断。
6. **缺帧与中断**：短暂缺点可保留阶段；缺点超过 500 ms、相邻帧间隔超过 500 ms、时间回退、身体明显不再符合站姿/正背面条件时丢弃未完成阶段，恢复后需重新合拢建立基准。滤波器短暂保持旧点仍可能带来滞后或误判。

## 快速肢体滤波

开合跳腕/踝运动较快；实时记录器和视频重识别对**仅此动作的双腕、双踝**使用随帧间隔放宽的跳变门槛：`max(原门槛, L近侧×(0.6 + 0.65×clamp(帧间隔/100ms, 0, 1)))`，原门槛为 `max(0.12 画面宽, 0.6×L近侧)`，这里 `L近侧` 是滤波器最近可信的单侧肩髋长度均值。大于门槛的跳变仍须稳定重捕获；其它点及其它动作保持原阈值。该处理可能接纳更多错误点，也可能仍漏掉过快动作，不能认为已解决真机快动作问题。合成轨迹中，每次 600ms、每 100ms 取样的示例发生漏计；建议降低动作速度并留意画面卡顿。此例不代表真人数据上的准确率。

## 个人校准与回放

先合拢建立基准，再在当前能做到的最佳**双臂、双脚同时张开**位置停留数帧，点击「个人校准 +1」；也可长按等待倒计时。连续三帧双臂夹角变化各 ≤12°、左右踝相对髋部及画面偏移变化各 ≤0.12 倍躯干，并与最新原始帧核对。采样时较小肩角 ≥55°、总间距增量 ≥0.12、双脚相对髋部和画面均各自向外 ≥0.04；原始帧也须符合这些最小条件。识别缺点、运动不稳或幅度不足时会说明原因，不保存、不计数。

成功时立即记一次，分别保存臂角目标 `min(135°, 采样角×95%)` 和双踝增量目标 `max(0.10, min(0.35, 采样增量×80%, 各侧相对髋部和画面的最小外移×95%/0.28))`。下次同帧同时达到两项且双脚相对髋部与画面的外移各达到目标的 28%（限定 0.04～0.10 倍躯干），再回到合拢位才计数；返位间距容忍为默认 0.18 与个人脚部目标一半的较小者。校准成功后必须先回到原合拢位并重新稳定采样，**丢帧不会绕过等待**；个人目标低于默认时仍累计姿势提醒。目标按账号和动作保存，可在账号页查看或恢复；这是当前个人目标，不代表姿势标准或安全。

开合跳可在成长星球按独立动作筛选，训练记录与其它动作分开。同版且骨架及逐帧缓存完整时，视频叠加骨架或纯骨架动画复用录制结果；骨架重算会按帧重放组内校准事件。视频重新识别只使用训练开始时的个人目标，不能把旧骨架帧号当成视频时间重放组中点击，也没有原来的重力时间轴；重识别不会覆盖历史成绩、原视频或骨架。视频方向、镜像与时空对齐仍需手机验证。

## 优缺点、替代方案与验证

- **优点**：可解释的双侧几何与状态机、单帧同步证据、逐侧外移和返位条件，有助于减少单独挥臂/迈腿及动作中途计数；支持账号隔离的个人目标和版本化回放。
- **局限**：没有脚离地证据；模型误检、身体或手机移动（较大的横移可能导致漏计）、两侧遮挡、转身、手/脚出框、跳跃时透视改变、姿态滤波滞后和快速动作都可能导致误计或漏计。`250ms`、角度、偏移及滤波阈值仅经合成数据检查，不能推断对不同体型、儿童或节奏的真实准确率。
- **比较**：只用腕角峰值的方法更简单，但更难排除挥臂；周期计数模型可研究节奏但周期本身不证明双臂双脚的动作质量；双摄/深度、脚部 IMU 或压力/接触传感器可能增加信息，却需设备、标定及数据验证。详见[索引中的同类方法比较](README.md)，不能把外部研究结果当作本项目成绩。
