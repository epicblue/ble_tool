# 俯卧撑算法

> [算法索引](README.md) · [人体骨架](pose-estimation.md) · 类型 `PUSHUP`；主成绩为有效次数。折凳和折刀分别见[折凳](chair-push-up.md)、[折刀](pike-push-up.md)；不标准独立入口已移除，其[旧记录](bad-push-up.md)仍可回放。以下阈值为未启用个人目标时的代码值。

## 输入与输出

使用滤波后、重力对齐的肩、肘、腕、髋、膝、踝二维点；输出有效次数、不标准次数、姿势提醒和当前深度进度。角度可使用可信的单侧或双侧融合；没有检测地面、手掌接触力或胸部实际高度。

## 实际判定流程

1. **姿态门槛**：躯干与水平夹角 `<55°`，手腕相对肩的下降比例 `>0.02`；否则清除当前动作阶段。
2. **深度双信号**：`e` 为肩—肘—腕角，`r` 为手腕相对肩高度 / 躯干长度，`B` 为观察到的撑起位 `r`。
   - 角度深度 `A = clamp((152 − e) / (152 − 100), 0, 1.25)`。
   - 下降深度 `D = clamp((B − r) / max(0.02, 0.72×B), 0, 1.25)`；基准不可用则该路不可用。
   - 阶段使用可用信号中的 `max(A, D)`。这里的特征来自已滤波骨架；判定使用当前深度，而额外 `0.5` 系数平滑深度主要用于进度显示，不能称为对模型原始帧计数。
3. **往返状态**：深度 `>0.22` 进入下放阶段；回到 `≤0.10` 时结算。阶段持续 `<350 ms` 的往返忽略；人体/躯干长时间不可用后放弃未完成阶段，具体丢失阈值为 500 ms。
4. **默认到位**：本次最小肘角 `≤100°` **或**最大下降深度 `≥0.85`。明显下放的参考为肘角 `≤122°` 或下降深度 `≥0.45`；极小且姿势未被判错的往返会忽略。
5. **姿势**：髋到肩—踝线的距离 / 躯干 `>0.13`、侧视时肩—髋—踝角 `<150°` 或膝角 `<120°` 可触发身体不直/跪姿提示；缺少相应度量时部分检查会退化，并不等于姿势正确。

一次往返按到位及姿势记为有效或不标准，并可给出幅度不足、身体不直、跪姿等提示。个人校准成功时立即计一次；后续采用个人起始角、深度与姿态容忍，回到撑起位后才计下一次，相关设置不代表标准或安全。

## 场景、优缺点

- **适合**：手机固定、单人训练、侧面或斜侧机位且肩肘腕髋腿尽量完整；先保持撑起位供基准建立。不同角度均需实测，不保证某个角度最准确。
- **优点**：肘角和肩腕相对位移互补，单侧可信时仍可工作；上下阶段分离、最短时长及个人目标便于解释。
- **局限**：`max` 能在一路低估时兜底，也会让一路错误偏大时误判到位；二维角度和躯干尺度仍受透视、遮挡、手机/身体移动影响；推理滞后和快动作可漏计。无法判断胸口与地面的距离、左右受力及真正的跪地接触。

## 与同类方法比较

单肘角阈值最简单，但更依赖机位；本项目加入相对位移，代价是需建立撑起基准且可能被异常值放大。时序分类或 RepNet 类方案可能覆盖更多动作节奏，但需要数据/部署验证，周期数本身不能证明每次姿势合格。多视角或深度方案可研究透视误差，需额外设备与标定；详见[同类方法与资料](README.md)。这些比较不是本项目实测排名。
